# DE Zoomcamp 💻
Zoomcamp on **DATA ENGINEERING** from <a href="https://datatalks.club/">DataTalks.Club</a>

1. Pipeline - Setting up an ingestion pipeline using Python script and PostgreSQL and dockerizing the complete process.
2. Workflow Orchestration - Creating and Scheduling of workflows using Kestra, GCP(BigQuery)
3. Data Warehouse - Ingesting raw data from sources into GCS and using it to create dataset into GCP(BigQuery). Hands on experience with BigQuery, BQ ML model, Deploying ML model.
4. Analytics Engineering - Setup `dbt` with `dbt-cloud` and build some fact and dims model for business usecase.
5. Batch Processing - Hands on experience with Spark, installing and using it for large scale data analytics and processing.
